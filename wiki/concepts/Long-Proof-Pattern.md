# Long Proof Pattern (长证明多智能体编排范式)

**Long Proof Pattern（长证明范式）** 是由 Google Antigravity 团队在 [[Teamwork]] 编排框架中提出并验证的高阶多[[AI-Agent|智能体]]设计模式。它专门针对开放性、高不确定性、推导深度极深的科研级难题（如理论计算机科学与高阶前沿数学公开猜想），将原本脆弱的单向推理转化为具有自我净化能力的**竞争对抗与锦标赛综合拓扑**。

---

## 1. 核心问题：为什么传统单/多智能体无法完成长定理证明？

在面对 PhD 级别的开放性未决命题时，现有 Agent 存在两个致命缺陷：
1. **隐性歧途深陷**：很多看似前途光明的证明路线，往往在推导出几十页之后才会暴露致命漏洞；单 Agent 一旦深陷其中，受注意力衰减与确定性偏见影响，极难主动回头重置。
2. **多智能体随声附和**：常规多智能体缺乏严密的批判工具，容易在早期就对一个包含微小破绽的代数变形达成错误共识，随后的推演全部沦为“精致的伪证”。

## 2. Long Proof 的四大核心工程设计

```text
               Long Proof 锦标赛网络与证伪闭环拓扑
  ┌──────────────────┐        ┌──────────────────┐
  │ 候选策略 A (Proposer)│◄───────►│ 严密证伪者 (Falsifier)│
  └────────┬─────────┘        └──────────────────┘
           │ (反对意见与幸存命题)
           ▼
  ┌──────────────────────────────────────────────┐
  │ 依赖有向无环图 (DAG) 证明规划与子任务拆解    │
  └────────┬─────────────────────────────────────┘
           │ 分发子任务
           ▼
  ┌──────────────────────────────────────────────┐
  │ 锦标赛综合树 (Tournament Synthesis Network)   │
  │ • 读取多组样本候选与证伪报告                │
  │ • 综合优势构想，迭代生成高阶解法             │
  └────────┬─────────────────────────────────────┘
           │ 沉淀经验与教训
           ▼
  ┌──────────────────────────────────────────────┐
  │ 跨轮次沉淀：陷阱注册表 (Pitfall Registry)     │
  └──────────────────────────────────────────────┘
```

### ① 竞争性策略搜索 (Competitive Strategy Search)
- 系统在初始阶段并行生成大量迥异的高阶证明策略。
- **1v1 证伪者配对**：为每一条策略路线专门配备一个以“定点推翻该假设”为单一目标的 **Falsifier Agent**。
- **保留被证伪的残骸**：即使某条路线被证明存在反例而被驳回，它的推导过程并不被直接丢弃，而是将其反对意见（Objections）作为结构化元数据附加在节点上——因为被驳回的路线中往往潜藏着可被复用的引理或构造灵感。

### ② 基于 DAG 的证明解耦 (Proof Decomposition)
- 经过筛选的胜出策略被进一步展开为一份具有清晰前置依赖的证明规划图。
- 依赖关系被形式化表示为**有向无环图 (DAG)**：彼此相互独立的引理子题在不同 Agent 上实现完全并行化推导；存在强因果因子的命题则严格按照拓扑排序（Topological Order）依次向下游传递，严格遵从 [[Agent-Scaling-Law]] 中的任务对齐原则。

### ③ 锦标赛综合网络 (Tournament Network)
- 在证明合成阶段，引入多层级的锦标赛树状结构。
- 综合树中的每一个节点会采样来自多个平行分支的半成品证明方案及对应的反驳报告。
- 节点吸收各家之长，修补漏洞并合成出更强健的新解；若该综合解再次被下游验证器击破，网络将携带累积的全部反对意见重新触发迭代。

### ④ 跨轮次陷阱注册表 (Pitfall Registry)
- 系统维系全局统一的共享知识目录（包含已形式化验证的事实、有效观察和已被确认不可行的死胡同）。
- 所有反例与推导破绽均被提炼为**答案无关的避坑规则（Pitfall Rules）**。后续轮次中所有新生成的智能体均以此作为负面先验，彻底杜绝在同一种数学陷阱中反复重蹈覆辙。

## 3. 实战验证战果

借助 Long Proof 模式，配合 **Gemini 3.1 Pro** 与 **Gemini 3.7 Flash**，Google 团队成功攻克了 7 项长期悬而未决的公开数学难题：
- 形式化验证：在高德纳环猜想（Knuth’s Cycles Conjecture）中生成的 40 页证明，已被完整导入 **Lean 4** 交互式定理证明器中并全部通过形式化编译检查。
- 评测战绩：在涵盖前沿开放问题的理论计算机科学基准 **TCSBench** 上，取得了 **71%** 的历史最高命中率。
