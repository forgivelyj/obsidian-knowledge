# Andrej Karpathy

## 📌 基本信息
- **身份**：AI 研究员、教育者、前 Tesla 人工智能总监、OpenAI 联合创始人。
- **代表性工作/理念**：nanoGPT、minGPT、CS231n 课程、LLM OS 概念、[[LLM-Wiki]] 知识管理模式。

## ⚙️ 核心思想与贡献
1. **[[LLM-Wiki]] 概念发起**：在 2026 年发表了关于个人知识库范式转变的文章，提倡将 LLM 作为个人知识库的自动化全职维护者。
2. **AI Native 工作流**：倡导将代码库与 Markdown 文本作为 LLM 理解世界和辅助人类思考的最自然载体。
